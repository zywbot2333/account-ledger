# 账号收支（Account Ledger）

多用户「账号收支」记账系统：每个用户注册后添加自己的账号（微信钱包、支付宝、银行卡等），逐笔记录收入/支出，自动汇总总账，并生成**日报 / 周报 / 月报 / 年报**。

> 本地/内网部署的个人记账工具，纯 PHP 原生开发，零第三方依赖。

## 功能特性

- 👤 **多用户隔离**：注册仅需用户名 + 密码；每个 IP 每天限注册 2 个账号（原子计数防并发绕过）
- 💳 **自定义账号**：添加/删除收支账号，卡片式展示各账号小计
- 🧾 **收支记账**：收入/支出分段切换，金额/日期/备注，流水分页，可删可改（删）
- 📊 **总账汇总**：总收入 / 总支出 / 结余，全局与分账号双层统计
- 📈 **四种报表**：日报（当日流水 + 账号分布）、周报、月报、年报（自研 SVG 柱状图，支持翻看历史期间、与上期对比）
- 🛠 **管理后台**：独立管理员会话，数据概览、用户管理（搜索/重置密码/删除）、注册限制记录
- ⚙️ **向导式安装**：填入数据库信息即可自动建库、建表、创建管理员、生成配置
- 📱 **响应式**：手机 / 平板 / 桌面自适应（360px ~ 1920px 全宽度测试通过）

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | PHP 8.2（原生，无框架），PDO + 预处理语句 |
| 数据库 | MySQL 5.7+（InnoDB / utf8mb4） |
| 前端 | 原生 HTML/CSS/JS，自研 SVG 图表，无任何 CDN 依赖 |
| Web | Nginx / Apache 均可（无需 URL 重写） |

## 快速开始

1. 克隆本仓库到 PHP 站点目录（要求 PHP ≥ 8.0，扩展 `pdo_mysql`、`mbstring`）
2. 确保目录可写（安装程序需要生成 `config.php`）
3. 浏览器访问 `http://你的域名/install.php`，按向导填写数据库信息与管理员账号
4. 安装完成后：
   - 前台：`http://你的域名/`
   - 管理后台：`http://你的域名/admin/login.php`
5. ⚠️ 安装完成后删除 `install.php`

> 详细的部署说明（phpStudy / Nginx 配置、php.ini 注意事项）见 [docs/开发维护文档.md](docs/开发维护文档.md)。

## 目录结构

```
├── config.php          # 站点配置（安装程序生成，不入库）
├── init.php            # 全站引导
├── install.php         # 安装向导
├── schema.sql          # 建表脚本（安装与增量建表共用）
├── index.php           # 总览
├── account.php         # 账号详情 / 记账
├── reports.php         # 日/周/月/年报表
├── login.php / register.php / logout.php
├── action.php          # 前台写操作
├── admin/              # 管理后台
├── inc/                # 数据库 / 鉴权 / 公共函数 / 布局
├── assets/             # 样式 / 图表脚本 / 交互脚本
└── docs/               # 使用教程 + 开发维护文档
```

## 安全说明

已内置：PDO 预处理（防注入）、输出转义（防 XSS）、CSRF 防护、bcrypt 密码哈希、会话固定防护、数据属主校验、注册 IP 原子限制。

定位为本地/内网工具，若部署到公网请先阅读 [docs/开发维护文档.md](docs/开发维护文档.md) 的「安全设计说明」章节（验证码、登录限频、HTTPS、关闭 display_errors 等）。
