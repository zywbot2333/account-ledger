# 账号收支 · 使用教程

一个部署在本地的多用户「账号收支」记账站点：每个用户注册后添加自己的账号（如微信钱包、支付宝、银行卡），逐笔记账，自动汇总总账并生成日/周/月/年报表。账号支持**自定义分类**与**标签**（已提现、多IP、封优惠、已二次、代理）。

- 前台地址：<http://localhost/>
- 管理后台：<http://localhost/admin/login.php>（管理员专用）

---

## 一、安装（首次部署）

1. 把程序放到站点目录（本文档对应 `A:\phpstudy_pro\WWW\error`，Nginx 根目录需指向该目录）。
2. 浏览器打开 <http://localhost/install.php>。
3. 页面会先做**环境检查**（PHP ≥ 8.0、pdo_mysql、mbstring、目录可写等），全部 ✓ 后填写：
   - 站点名称（默认「账号收支」）
   - 数据库：地址、端口、**库名**（不存在会自动创建）、用户名、密码
   - 管理后台：管理员用户名、密码（至少 8 位）
4. 点击「开始安装」：自动建库 → 建表 → 创建管理员 → 生成 `config.php`。
5. 看到「安装完成」即可进入前台和管理后台。
6. ⚠️ 安装完成后**删除网站根目录下的 `install.php`**，防止他人重复安装。

> 再次打开 install.php 时，若检测到已安装会直接提示「已经安装过了」，不会破坏数据；确需重装需手动勾选「强制重新安装」（会清空所选数据库中的同名表数据）。

## 二、普通用户功能

### 1. 注册 / 登录

- 注册只需**用户名 + 密码（两次确认）**，不需要手机号邮箱。
- 用户名：2-20 位中文/字母/数字/下划线；密码：6-64 位。
- **每个 IP 每天最多注册 2 个账号**（次日自动恢复），防止批量注册。

### 2. 添加账号

总览页点击虚线框「＋添加账号」：

- 账号名称（必填，如：微信钱包、招商银行卡）
- 分类（可选，从你自己的分类中选择；还没有分类可先看下方「分类管理」）

### 3. 分类管理

账号多了以后可以用分类归组：

- 总览页右上角「**管理分类**」面板：**添加**新分类、**重命名**、**删除**（删除分类不影响账号，旗下账号自动变为“未分类”）
- 总览页账号列表上方出现**分类筛选条**（全部 / 各分类，含账号数），点击即筛选
- 卡片上账号名下方会显示所属分类

### 4. 账号标签

每个账号可勾选一组固定标签：**已提现、多IP、封优惠、已二次、代理**。

- 在账号详情页的「**账号设置**」卡中点选，**点选即保存**
- 勾选的标签会以彩色徽章显示在**总览的账号卡片**和详情页顶部，一眼识别账号状态

### 5. 记账（记一笔）

点击任意账号卡片进入账号详情页：

1. 选择类型：**支出**（红）/ **收入**（绿）
2. 填写金额（最多两位小数）、日期（默认今天，可补记历史）
3. 保存后立即计入该账号与总账

流水列表中每笔记录可单独删除（✕ 按钮）；账号页「删除账号」会**连同其全部流水一起删除**，操作前有确认提示，请谨慎。

### 6. 查看报表

顶部导航「报表」进入，共四种维度：

| 报表 | 统计内容 |
|---|---|
| **日报** | 某一天的收支总计（对比前一日）+ 各账号当日分布图 + 当日全部流水清单 |
| **周报** | 本周（周一~周日）每天的收入/支出柱状图 + 账号明细 |
| **月报** | 本月每天的收支走势 + 账号明细 |
| **年报** | 全年 12 个月的收支对比 + 账号明细 |

- 顶部胶囊按钮「← / →」可翻看上一期/下一期（日报即前一天/后一天），支持「回到今天 / 回到本期」。
- 每张统计卡上会显示与上一期的对比（如「较上期 -95%」）。
- 图表中的**虚线参考线**为该期间各系列的平均值，便于对比单日/单账号表现。

### 5. 数据汇总逻辑

- **总览页**：总收入 / 总支出 / 结余 = 全部账号全部流水的合计；每个账号卡片单独显示小计。
- 数据按用户完全隔离，互相不可见。

## 三、管理后台

入口：<http://localhost/admin/login.php>（与前台账号互相独立）。

### 1. 数据概览

- 用户总数、今日新增用户（含今日注册 IP 数）、收支账号总数、流水总数
- 最近注册用户列表（用户名 / 注册 IP / 时间）
- **注册限制记录**：每个 IP 每天的注册计数，达到上限的会标红

### 2. 用户管理

- 支持按**用户名或注册 IP** 搜索，分页展示
- 每位用户可见：账号数、流水数、总收入、总支出
- **重置密码**：点击后输入新密码（至少 6 位），用于帮用户找回密码
- **删除用户**：级联删除该用户的全部账号与流水，不可恢复，操作前有强确认

### 3. 修改密码

后台侧边栏「修改密码」，需验证当前密码，新密码至少 8 位。

## 四、常见问题

**Q：忘记用户密码？**
让管理员在后台「用户管理」中重置。

**Q：注册提示已达上限？**
同一 IP 当天已注册 2 个账号，次日 0 点后自动恢复；管理后台可查看记录。

**Q：记错账了怎么办？**
到账号详情页删除那一笔，重新记录。误删整个账号无法恢复，只能重新添加并补录。

**Q：想修改注册限制或每页条数？**
编辑站点根目录 `config.php` 中的 `DAILY_REG_LIMIT`（默认 2）和 `TX_PER_PAGE`（默认 20）。

**Q：数据会丢吗？**
数据都在 MySQL 里，建议定期备份（见维护文档的备份章节）。
