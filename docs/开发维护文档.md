# 账号收支 · 开发维护文档

多用户个人记账站点。技术栈：**PHP 8.2（原生，无框架） + MySQL 5.7 + Nginx**，前端为原生 HTML/CSS/JS（零外部依赖，图表为自研 SVG 渲染器）。

- 前台：`http://localhost/`
- 管理后台：`http://localhost/admin/login.php`
- 安装程序：`http://localhost/install.php`

---

## 二、数据库设计（5 张表，InnoDB / utf8mb4）

| 表 | 说明 | 关键字段 |
|---|---|---|
| `users` | 前台用户 | `username`(唯一), `password_hash`(bcrypt), `reg_ip`, `created_at` |
| `admins` | 管理员（与用户独立） | `username`(唯一), `password_hash` |
| `reg_log` | 注册 IP 限制计数 | `ip`+`reg_date`(唯一索引), `cnt` 当日已注册数 |
| `accounts` | 收支账号 | `user_id`, `name`, `remark` |
| `transactions` | 收支流水 | `user_id`, `account_id`, `type`(1=收入 2=支出), `amount` DECIMAL(12,2), `note`, `occurred_at`(DATE) |

- 索引：`transactions(user_id, occurred_at)` 支撑报表区间查询；`(account_id)` 支撑账号页。
- **升级表结构**：把新的 `CREATE TABLE IF NOT EXISTS ...` 语句追加到 `schema.sql` 即可，`ensure_schema()` 会自动为存量环境补建缺失的表（无需手动执行 SQL）。

## 三、核心机制

### 1. 会话与鉴权（前台/后台双会话）

- 前台登录态：`$_SESSION['uid']`；后台：`$_SESSION['aid']`，二者互不干扰，可同时登录。
- 密码一律 `password_hash` / `password_verify`；登录成功 `session_regenerate_id(true)` 防会话固定。
- Cookie：`httponly + SameSite=Lax`。

### 2. CSRF

全站写操作（前台 `action.php`、后台 `action.php`/登出/改密）都要求表单携带 `csrf` 隐藏域，服务端 `csrf_ok()` 用 `hash_equals` 校验。

### 3. 注册 IP 限制（原子占位）

```
INSERT INTO reg_log (ip, reg_date, cnt) VALUES (?,?,1)
  ON DUPLICATE KEY UPDATE cnt = cnt + 1;
SELECT cnt ...;  -- 同一事务内回读
if (cnt > DAILY_REG_LIMIT) rollback → 拒绝注册
```
利用行锁让并发请求串行占位，提交前超额即回滚，杜绝并发绕过。日期取 PHP 侧 `date('Y-m-d')`（与站点时区一致，避免依赖 MySQL 时区）。

### 4. 报表分桶

- 周/月报：按 `occurred_at`（天）分组；年报：`DATE_FORMAT(occurred_at,'%Y-%m')` 分组；SQL `GROUP BY` 后在 PHP 侧补齐空桶（无数据的日期补 0）再交给 `charts.js` 渲染。
- 期间计算用 `DateTimeImmutable`；周一用 `format('N')` 手动回推（避开 PHP「sunday this week」的歧义行为）。
- 日报特殊：图表为**按账号分布**，另输出当日流水清单。
- 对比上一期：单独跑一条 SUM 查询（`period_range($p, $o-1)`）。

### 5. 增量建表 ensure_schema()

每次请求 `SHOW TABLES` 与 `schema.sql` 中声明的表名对照，只 `CREATE` 缺失的表（一次轻量查询，开销可忽略）。新环境全量建表，老环境自动升级补表。

## 四、配置项（config.php）

| 常量 | 默认 | 说明 |
|---|---|---|
| `DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASS` | — | 数据库连接（安装程序写入） |
| `APP_NAME` | 账号收支 | 站点名称（导航、标题、页脚） |
| `APP_DEBUG` | false | true 时数据库异常直接抛出（排障用，生产保持 false） |
| `DAILY_REG_LIMIT` | 2 | 每 IP 每日注册上限 |
| `TX_PER_PAGE` | 20 | 账号流水每页条数 |

## 五、安装程序 install.php

- 自包含（只依赖 `inc/helpers.php`，不加载站点配置），三步：环境检查 → 填写信息 → 自动执行。
- 自动执行内容：连接服务器 → 库不存在则 `CREATE DATABASE`（需账号有建库权限，否则提示手动建库）→ 导入 `schema.sql` → 创建首个管理员（已存在则跳过）→ 生成 `config.php`。
- 已安装检测：`config.php` 存在且能连通数据库 → 显示「已经安装过了」。强制重装需显式勾选，会 `DROP` 目标库中 5 张表后重建（**清空数据**）。
- **安全**：装完务必删除 `install.php`（或至少确保站点不对公网开放）。

## 六、部署 / 迁移到新环境

以 phpStudy（Nginx + PHP 8.2 + MySQL）为例：

1. 拷贝整个 `error/` 目录到新机站点目录；数据库导出导入（见下节）。
2. Nginx 站点根目录指向该目录（phpStudy：`Extensions\Nginx1.15.11\conf\vhosts\*.conf` 中 `root` 字段，改后 `nginx -t` 并 `nginx -s reload`）。
3. PHP 注意：phpStudy 的 php.ini 若残留 `track_errors=On`（PHP7 遗留指令）会导致 PHP 8 启动失败，删除/注释该行；确认 `extension_dir` 指向 `ext` 目录且已启用 `pdo_mysql`、`mbstring`。改完重启 php-cgi（phpStudy 会自动拉起）。
4. 删除 `config.php` 后访问站点，会自动跳转 `install.php` 走安装向导。
5. 时区统一为 `Asia/Shanghai`（`init.php` 与 php.ini 双保险）。

## 七、备份与恢复

```bash
# 备份（Windows 下在 MySQL bin 目录执行）
mysqldump -h127.0.0.1 -uDB_USER -p DB_NAME > backup_20261004.sql

# 恢复
mysql -h127.0.0.1 -uDB_USER -p DB_NAME < backup_20261004.sql
```

也可用 phpStudy 自带的数据库备份功能。建议每周备份一次；升级代码前先备份。

## 八、常见维护任务

| 任务 | 做法 |
|---|---|
| 改注册限制 | `config.php` → `DAILY_REG_LIMIT` |
| 改站点名 | `config.php` → `APP_NAME` |
| 新增数据表 | 在 `schema.sql` 追加 `CREATE TABLE IF NOT EXISTS` 语句即可自动补建 |
| 清空某用户数据 | 后台「用户管理」删除该用户（级联清理）；或写 SQL |
| 管理员忘记密码 | 直接改库：`UPDATE admins SET password_hash='<新bcrypt哈希>' WHERE username='admin';`（哈希可用 `php -r "echo password_hash('新密码', PASSWORD_DEFAULT);"` 生成） |
| 排查报错 | 查看 `Extensions\php\php8.2.9nts.log`（php.ini 的 error_log） |

## 九、安全设计说明

已实现：预处理语句（全部查询）、输出转义（`e()`）、CSRF 防护、bcrypt 密码、会话固定防护、登录态与资源的属主校验（用户只能访问自己的数据）、金额/日期/用户名严格正则校验、注册 IP 原子限制、管理后台独立会话。

已知边界（本地部署定位，若上公网需补齐）：

- 登录/注册无验证码、无登录频率限制（可加 simple rate-limit 表）；
- `display_errors=On`（phpStudy 默认，公网应关闭并只留日志）；
- 未强制 HTTPS；
- 管理后台建议额外加 IP 白名单（Nginx `allow/deny`）。

## 十、故障排查速查

| 现象 | 原因 / 处理 |
|---|---|
| PHP 启动报 `track_errors is no longer available` | php.ini 删除/注释该行（PHP8 已移除） |
| 页面报「could not find driver」 | php.ini 未启用 `extension=pdo_mysql`，改后重启 php-cgi |
| 中文入库报 `Incorrect string value (1366)` | 客户端发来了非 UTF-8 内容；确认页面/请求编码为 UTF-8（浏览器正常，多为 curl 脚本编码问题） |
| 访问出现 403「未找到默认的索引文件」 | Nginx 根目录指错或未经过 PHP 路由，检查 vhost `root` 是否指向本目录 |
| 总览报数据库错误 | `config.php` 中连接信息与实际不符；或库被删，删除 config.php 重新走安装 |
| 端口 3306 连不上 | MySQL 服务未启动（phpStudy 启动 MySQL） |
